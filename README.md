## 🚀 Key Features

### 🧠 AI Decision Intelligence Layer (DETECT → EXPLAIN → PREDICTS → SIMULATES → RECOMMENDS)
- 📡 **Business Radar (Risks & Opportunities):** Real-time deterministic detection of revenue contraction, margin decay, customer churn, and fast-growing high-margin product opportunities with 4-step drilldowns (*What happened? → Why? → What could happen next? → What can I do?*).
- 🔬 **Root Cause Analysis & "Ask Why":** Multi-dimensional mathematical decomposition isolating exact contributor shares across products, regions, categories, and volumes, synthesized into plain-English AI explanations.
- 🧪 **What-If Business Simulator:** Read-only, in-memory sandbox allowing merchants to test price elasticity, promotional discounts, demand shifts, and portfolio pruning with side-by-side Baseline vs. Simulated comparisons.
- 📋 **AI Action Planner:** Prioritized strategic playbooks that bridge the gap from data discovery to actionable execution with one-click simulator links.

### 🤖 AI-Powered Smart CSV Import & Schema Auto-Mapping
- **Intelligent Header Detection:** Upload any vendor or sales CSV without strict formatting. Powered by **Google Gemini API** (with Groq fallback), Nueradash automatically maps arbitrary column headers to standard schema fields.
- **Interactive Review:** Preview sample data, inspect AI column mappings, adjust target fields, or skip unneeded columns before ingestion.
- **Auto Product Discovery:** Automatically identifies new products in sales imports and registers them to your catalog.

### 📦 Product Master & Profit Engine
- **Catalog Management:** Add, edit, and manage products with SKU/Product ID, category, cost price, and selling price.
- **Automated Profitability Analysis:** Automatically calculates per-unit margin and total profit across all transactions:
  $$\text{Total Profit} = (\text{Selling Price} - \text{Cost Price}) \times \text{Quantity}$$

### 📊 Interactive Visual Analytics Dashboard
- **Executive KPI Cards:** Real-time visibility into Total Sales Revenue, Total Profit, Total Transactions, and Average Order Value (AOV).
- **Comprehensive Chart Suite (Recharts):**
  - 📈 **Sales Trend Over Time:** Historical daily revenue trajectory.
  - 🔮 **7-Day Sales Forecast:** Predictive time-series modeling using linear regression analysis.
  - 🏆 **Top 5 Revenue Products:** Horizontal bar chart highlighting highest grossing items.
  - 🗺️ **Regional & City Breakdown:** Geographic performance visualization across states and cities.
  - 🏷️ **Category Breakdown:** Doughnut chart of category revenue distribution.
  - 💳 **Payment Method Distribution:** Breakdown of transaction volumes across UPI, Card, Cash, etc.
  - 👥 **Customer Intelligence:** Top spending customers & repeat vs. new customer conversion ratio.

### 💡 Automated AI Executive Summaries & Chatbot
- **Auto-Generated Summaries:** Instant natural-language summaries generated by LLMs on data upload, summarizing top performers, market trends, and actionable business recommendations.
- **Interactive AI Sales Assistant:** Integrated conversational chatbot trained on your live dataset. Ask questions like *"Which product is driving the most profit?"* or *"Who are my top customers in Delhi?"*.

### 📋 Granular Sales Record Management
- **Hierarchical Date-Grouped View:** Clean, collapsible daily breakdown of all transaction records.
- **Date Range Filters:** Filter records across custom date windows.
- **CRUD & Instant Re-Sync:** Edit transactions inline or delete erroneous rows with automatic background recalculation of AI insights and summaries.

### 🔐 Security, Multi-Tenancy & UX
- **Multi-Tenant Data Isolation:** Secure JWT authentication with bcrypt password hashing; all records and metrics are strictly isolated per user.
- **Theme Support:** Modern dark and light theme toggle with smooth transitions.

## ⚡ Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.x or higher)
- [MongoDB](https://www.mongodb.com/) (Local instance or MongoDB Atlas connection URI)
- [Google Gemini API Key](https://ai.google.dev/) or [Groq API Key](https://console.groq.com/)
- [Flutter SDK & Android Studio](https://docs.flutter.dev/get-started/install) (for Android mobile app)

---

### 1. Clone & Setup Repository

```bash
git clone https://github.com/aswin-b-07/NeuraDash.git
cd nueradash
```

---

### 2. Backend Setup (Shared by Web & Mobile)

1. Navigate to the backend directory:
   ```bash
   cd backend
   npm install
   ```

2. Create a `.env` file in the `backend/` directory:
   ```env
   PORT=5000
   MONGO_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/nueradash
   JWT_SECRET=your_super_secret_jwt_key_here
   GEMINI_API_KEY=AIzaSy...your_gemini_api_key_here
   # GROQ_API_KEY=gsk_... (optional fallback)
   ```

3. Start the backend server:
   ```bash
   node server.js
   ```
   *The server will start on `http://localhost:5000` with confirmation: `✅ MongoDB Connected`.*

---

### 3. Web Frontend Setup (React.js)

1. In a new terminal window, navigate to the frontend directory:
   ```bash
   cd frontend
   npm install
   ```

2. Start the React development server:
   ```bash
   npm start
   ```
   *The frontend application will open automatically at `http://localhost:3000`.*

---

### 4. Mobile App Setup (Flutter Android)

The Flutter mobile application communicates with the exact same Node.js/Express backend and MongoDB database.

1. Open the `mobile` folder in **Android Studio** or **VS Code**.
2. Install Flutter packages:
   ```bash
   cd mobile
   flutter pub get
   ```

3. **Configure Backend URL for Android:**
   - **Android Emulator:** Defaults to `http://10.0.2.2:5000/api` in `mobile/lib/core/constants/api_config.dart`.
   - **Physical Device:** Change `baseUrl` in `api_config.dart` to your computer's LAN IP (e.g. `http://192.168.1.50:5000/api`).

4. Run the app on your connected Android device or emulator:
   ```bash
   flutter run
   ```

## 🌐 Environment & Network Configuration

### Backend (`backend/.env`)
| Variable | Required | Description | Example |
|---|---|---|---|
| `PORT` | No | Express server listener port (defaults to 5000) | `5000` |
| `MONGO_URI` | **Yes** | MongoDB connection string (Atlas or Local) | `mongodb://localhost:27017/nueradash` |
| `JWT_SECRET` | **Yes** | Secret key for signing JSON Web Tokens | `supersecretkey123` |
| `GEMINI_API_KEY` | **Yes** | API key from Google AI Studio | `AIzaSy...` |
| `GROQ_API_KEY` | No | Optional secondary / fallback LLM provider | `gsk_...` |

### Mobile Network Mapping (`mobile/lib/core/constants/api_config.dart`)
| Environment | Host Address |
|---|---|
| **Android Emulator** | `http://10.0.2.2:5000/api` |
| **Physical Device (WiFi)** | `http://<YOUR_LOCAL_IP>:5000/api` |
| **Production Server** | `https://api.yourdomain.com/api` |

## 📡 API Reference

All protected endpoints require the HTTP Authorization header: `Authorization: Bearer <jwt_token>`.

### 🧠 Decision Intelligence (`/api/decision`)
| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `GET` | `/api/decision/overview` | **Yes** | Aggregated snapshot of Radar, Root Cause, Action Plan, and Product catalog |
| `GET` | `/api/decision/radar` | **Yes** | Unified list of detected 🔴 Business Risks and 🟢 Growth Opportunities |
| `GET` | `/api/decision/root-cause` | **Yes** | Period-over-period multi-dimensional driver decomposition & AI analysis |
| `POST` | `/api/decision/simulate` | **Yes** | Execute in-memory sandbox What-If simulation (Price, Discount, Demand, Regional) |
| `GET` | `/api/decision/action-plans` | **Yes** | Synthesized prioritized action recommendations |
| `GET` | `/api/decision/predictions` | **Yes** | Extended 14-day multi-horizon predictive forecasting and trajectory |

## 📑 Target CSV Schema

When importing sales datasets, Nueradash matches columns to the standard target fields:

| Field Name | Type | Description |
|---|---|---|
| `Sale ID` | String | Unique transaction identifier |
| `Customer Name` | String | Name of the customer |
| `Region` | String | Geographical region or State |
| `Customer Email` | String | Email address of customer (optional) |
| `Customer Phone` | String | Contact phone number (optional) |
| `Product ID` | String | SKU or Product identification code |
| `Product Name` | String | Name of product sold |
| `Category` | String | Product department or category |
| `Quantity` | Number | Units purchased in order |
| `Price` | Number | Selling price per unit |
| `Date` | Date/String | Transaction timestamp (e.g., `YYYY-MM-DD`) |
| `Location` | String | Branch, store, or city |
| `Payment Method` | String | Payment mode (`UPI`, `Credit Card`, `Cash`, `Debit Card`) |
